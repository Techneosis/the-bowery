## What's new

**`bowery watch <config>`: one background watcher for everything in flight.**
An orchestrator with agents, PRs and CI runs going no longer has to poll them
in a loop. `bowery watch` checks them in the background and exits as soon as
something worth acting on changes, so the exit is the wake-up:

```
repo acme/web
machine swarm-box                  # agent lines below are on that machine
agent fixer                        # idle | done | blocked | gone (working is quiet)
pr 412                             # OPEN | MERGED | CLOSED, /CONFLICTING
run ci.yml feature-x               # latest run on a branch or commit (in progress is quiet)
ticket T-12                        # anything else: ~/.config/bowery/watch.d/ticket T-12
```

- **What it prints:**
  - `CHANGED:` with the lines that changed, and `ALL:` with everything;
  - `STILL BLOCKED:` while an agent waits at a dialog;
  - `HEARTBEAT` after `--max` (45m by default) if nothing changed.
- **Coarse states only:** each kind reports a state, never progress text, so it
  wakes on transitions rather than narration.
- **Your own kinds:** a script in `~/.config/bowery/watch.d/`. Its last line of
  output is the value, and a leading `~` marks it quiet.

**A box can dispatch under a name to its own server.**
A top-level `identity_command` in a machine's own config allows `--as` without
`--machine`, with the same contract as a saved machine's. For example, a job on
the box can hand work to an agent that works as a given person. Local git for
that agent runs through it, including `done`'s checks.
