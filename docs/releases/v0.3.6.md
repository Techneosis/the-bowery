## A record for an agent started by hand

**`bowery adopt <name> --launcher CMD --gated|--ungated`** gives a live agent
that was started by hand, with no dispatch record, one that `bowery resume`
can use: its session from herdr, its folder from its pane, and the launcher
and permission mode you give. Nothing restarts. That's how a seat started in
its pane can come under a job that resumes it later.

- **`--gated` or `--ungated` is required** for a new record of a claude
  agent: bowery can't see how a hand-started claude was launched, and resume
  would otherwise guess its permissions.
- **On an existing record,** `--launcher` sets or changes its launcher, and
  `--gated`/`--ungated` its permission mode. A record from an older bowery
  that lacks a session or a folder isn't filled in from a live agent; `bowery
  done` it, then `adopt` it.
- **The folder is where the claude runs,** not where its shell has moved to.
- **Checked before it's written:** no session reported, two live agents with
  the name, or a bad name or path refuses, with nothing written or said.
  Paths starting with `-` go after `--`.
- **Worktree paths are now optional;** `adopt <name> <path>...` still adds
  worktrees as before.
- `adopt` takes the same name lock as `resume` and `dispatch`.

## `--machine` on a Mac with a long temp folder

ssh's control socket used to live in `$TMPDIR`, which on macOS (and inside
some tools' sessions) is long enough to pass the 104-byte limit on a socket
path, so every `--machine` call failed with "too long for Unix domain
socket". It now lives in a short private folder: `$XDG_RUNTIME_DIR` when
it's at most 34 bytes and absolute, else `/tmp/bowery-<uid>`. Either must be
a real folder (not a symlink), mode 0700 and yours, under folders owned by
root or you that nobody else can write to (unless sticky, as `/tmp` is). A
root-owned symlink on the way, as macOS's `/tmp -> private/tmp`, is followed
and its target checked the same way. 34 is the room ssh
leaves under macOS's limit once it adds the socket's name and its own
temporary suffix. If neither is safe, ssh runs without sharing a connection.
