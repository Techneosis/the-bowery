## What's new: v0.5.3's fixes, published

v0.5.3 was tagged but never published: its macOS verify failed on
the new `tests/test_ci_local.py`, because the runner's `bash` is 3.2 and
`scripts/ci-local` needs bash 5.1's `wait -n -p`. This release is v0.5.3
plus that one fix; v0.5.3's notes say what's in it.

- **`scripts/ci-local` waits for each machine once.** Under bash 5.3,
  `wait -n` hands back a job it already reported while its pid is still
  in the list. When this machine passed first, a failure on the other
  machine went unseen and ci-local exited 0. It now exits 1.

### Tests

- `tests/test_ci_local.py` skips when the `bash` on PATH has no
  `wait -n -p`, which ci-local needs to run.
- The `hands_off_env` resume tests mark a python process: macOS 26 hides
  an Apple platform binary's environment from `ps -E`.
- The slow-plugin test accepts the kill in the plugin's `describe` too.
