## A split or tab starts in the folder it records

`dispatch --split` and `--tab` now always open their pane with `--cwd`.
Without it, herdr opens the new pane in the source pane's folder, which
isn't the one recorded when bowery runs from elsewhere (`--from`), and a
later `resume` would look for the session in the wrong place.

## Identities and folders

- **A new pane always becomes its identity**, with the machine's
  `identity_command`, as before.
- **A resume in the agent's own terminal no longer runs the identity
  command again.** That shell is already the identity's, since `exec`
  replaced it at dispatch, and a `sudo -u` style wrapper may not let the
  identity run the command itself. The identity's variable is still read
  back, and a shell that has lost it is refused.
- **After the switch, a new pane goes back to the agent's folder**, and
  bowery waits until the pane reports it is there. An identity command that
  starts in the identity's home (`sudo -i` does) used to leave the agent
  there, and the session filed under the wrong folder. If the pane can't get
  there, the start fails and is taken back.
- **`dispatch --pane` with `--as`** records the folder the pane is in after
  the switch, which is where the agent really starts.

## Upgrading

`bowery upgrade`, or the install line in the README.
