## Say when herdr is too old to report sessions

herdr before 0.9.5 has no `agent_session` in `agent list`, and the Bowery
reads every Claude session id from it. On an older herdr, `dispatch`
records no session, `resume` can't confirm one, and `adopt` refuses a seat
started by hand. Those messages now say why: herdr here reports no agent
sessions at all, and needs 0.9.5 or later.

## Upgrading

`bowery upgrade`, or the install line in the README. On a machine whose
herdr is older than 0.9.5, upgrade herdr too.
