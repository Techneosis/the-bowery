## dispatch checks the agent started on its prompt

herdr's `agent prompt` can return with the prompt typed into the agent's
composer and never submitted. The agent then sits idle, and dispatch used
to report success.

Now, after `bowery dispatch <name> ... -- <prompt>`:

- dispatch waits up to 60s for the agent to start (working, blocked or done).
- Still idle: it sends one more Enter, and waits 15s more.
- Still idle after that: it prints its JSON line as usual, then exits 1 with
  `agent <name> never started working; its prompt may be unsubmitted:
  herdr agent read <name>` (with `--machine <label>` for a remote agent).
  The agent and its record are left as they are, for `herdr agent read`,
  `bowery done` or a retry by hand.
- `--no-start-check` skips the check, for a caller that means to leave the
  agent idle. Without a prompt, or with `--wait`, there is nothing to check.

## Upgrading

`bowery upgrade`, or the install line in the README.
