## What's new: the private projection

- **`bus.PrivateFold` folds a region's private records** (`private.card`,
  `private.request`, `private.ticket`, `private.hide`, `private.note`)
  into cards, requests, tickets, hides and notes, in a keyed snapshot:
  `{v, cursor, meta, lists}`, each list's entries `{key, v}`, every list
  always there. A record merges over the ones before it for its key, in
  (at, producer, seq) order, and `remove` (`undo` for a hide) starts the
  key afresh, so the fold doesn't depend on the order records arrive in.
  Keys carry a `private/` prefix.
- **`office private ls [--type T] [--json]` and `office private show <key>`**
  read the fold of every `private.*` record your seat reads from the local
  node. `--json` prints the snapshot.
- **`office bus publish --topic T`** is the same as the positional topic,
  and a `private.*` record is checked against its schema
  (`bus.CheckPrivate`) before it reaches the node: unknown fields, a
  card without a subject, a link that isn't http(s), and so on.
- **Shared never points at private.** A node refuses a shared topic's
  event that names a `private/` key anywhere in its subject, actor or
  data (`bus.NamesPrivate`). A private record may name any shared key.

### Tests

- `TestPrivateFoldShape`: every list, the cursor, merges, removals,
  nesting, and the skipped records named with why.
- `TestPrivateFoldParity`: 200 random interleavings across producers,
  with a record seen twice and snapshots taken mid-way, all fold to the
  same bytes as the in-order replay, which is the same twice.
- `TestPrivateFoldIgnoresShared`, `TestCheckPrivate`,
  `TestSharedNeverNamesPrivate`.
- `test_private_projection` (python): publish with `--topic`, the schema
  refusals, `office private ls|show`, byte-identical replays, and a seat
  that reads no `private.*` getting an empty fold.
