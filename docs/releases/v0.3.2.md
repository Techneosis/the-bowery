## Start agents through a launcher

**`--launcher <command>` on `dispatch` and `resume`.** Some agents have to be
started with an environment of their own, set up by a wrapper that then
execs claude. `herdr agent start` only runs claude's own executable, so with
a launcher bowery runs `<command> <claude's arguments>` in the pane's shell
itself. It waits for herdr to see the claude agent there, names it, answers
the folder-trust dialog as usual, and goes on as before: tag, record, prompt.

```
bowery dispatch seat --cwd ~/src/app --launcher 'my-launcher seat' -- "start"
bowery resume seat                        # through the same launcher again
bowery resume other --launcher 'my-launcher other'   # add one at a resume
bowery resume other --no-launcher         # or drop it
```

- **The launcher must exec claude.** One that doesn't fails the start, with
  the pane's last lines, and what bowery made for it is taken back. In a
  pane that isn't bowery's (`--pane`), it says the line ran there.
- **On a resume it must pass claude's arguments on:** a launcher that starts
  claude on another session than the record's is refused, that claude loses
  the agent's name, and the record keeps its own session. A session herdr
  doesn't confirm is never written over the record's.
- **It's typed into a shell, so it must be one plain line:** not empty, no
  control or format characters, and not another option taken by mistake
  (`--launcher --dry-run` is refused; `--launcher=VALUE` for a command that
  really starts with `-`).
- **For a launcher start, `--timeout` is the whole start's total.**
- **A recorded launcher is checked again** before a resume types it.
- **It's recorded,** so `resume` uses it again without being told.
- **Only for `--kind claude`.**
