## `--space`: a swarm tab in another workspace, for one call

`bowery dispatch <name> --space <label>` and `bowery resume <name> --space
<label>` put the agent's new tab in that workspace instead of the configured
`swarm`. It's found by its label, or made if it isn't there, and it closes
with its last tab, as swarm does. The config's `swarm` stays the default for
every other call, and only swarm is moved to the bottom of the list.

- On `dispatch` it goes only with `--swarm` (the default placement), and any
  other placement is refused.
- On `resume` it names where a *new* tab goes. An agent whose own pane or tab
  is still open comes back there first, as before. A `--workspace` agent with
  `--space` gets a tab in that workspace instead of a workspace of its own.
  `--space` with `--workspace` is refused.
- It isn't recorded. A record still names the tab it owns, so `done` brings
  the agent home as usual, and a later resume without `--space` uses swarm.
- A label is letters, digits, `.`, `_` or `-`, up to 48 characters. A bad
  one, or two different ones, is refused. With `--json` that's one `refused`
  line, like any other usage error.

## Upgrading

`bowery upgrade`, or the install line in the README.
