## A launcher knows the Bowery is starting it

`bowery dispatch --launcher` and `resume` through a launcher now set
**`BOWERY_LAUNCH=1`** for the launcher. The Bowery sends the agent's first
prompt itself (the dispatch prompt, or the resume notice), so a launcher
that has an opening prompt of its own can leave it out when it sees the
variable. The agent then gets one first turn, not two.

The variable is set in front of the launcher line, so it reaches the line's
first command: a launcher written as `cd x && my-launcher …` gives it to `cd`
alone (use `env …` or a wrapper script instead). A pane whose shell is fish
older than 3.1 doesn't accept `VAR=1 cmd`.

## Upgrading

`bowery upgrade`, or the install line in the README.
