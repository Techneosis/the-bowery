## What's new: `private.*` never leaves a region

- **`private.*` is private in every region**, whether the region file's
  `[bus] private` lists it or not (`bus.AlwaysPrivate`). Before, a
  region file without that line would replicate `private.*` events to
  any peer whose `may_read` covered them, `"*"` included. `[bus] private`
  still adds topics of the region's own.
- **A node that a peer sends a private event refuses it and logs it.**
  The refusal was already in the reply. Now the receiving node, the side
  whose privacy it was, also writes it to its own log
  (`office bus: refused <ref> from <peer>: … private topic …`), on a
  push to it and on a pull it makes. `bus.NodeConfig` gains `Logf`.

### Tests

- `TestPrivateIsAlwaysPrivate`: `private.*` is private and goes neither
  way with no `[bus] private`, even under a `"*"` read.
- `TestNoPeerSetEverGetsPrivate`: forty random peer rule sets, pushed
  and pulled, and the peer never holds a `private.*` event.
- `TestPrivateArrivalIsRefusedAndLogged`: a hand-made push carrying a
  private event is refused, the rest kept, and the receiver logs it once.
