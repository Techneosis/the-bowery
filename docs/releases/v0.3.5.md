## Start an agent again in a new conversation

**`bowery resume <name> --fresh`** starts a dead agent again where it was
(its directory and worktrees, its machine and `--as`, its pane or tab, its
launcher), but in a **new** conversation instead of resuming its old one.
That's for an agent idle long enough that reloading its whole conversation
would cost more than starting over from its notes.

- **Same checks, lock and guards as a resume,** with `--if-dead` and
  `--not-within`. It counts as a resume, so `--not-within` still holds.
- **Its first message** says it was started in a new conversation, its
  earlier one isn't loaded, and to check what's already done before redoing
  anything. A prompt after `--` follows.
- **No session needed** on the record, so an older record without one can be
  started fresh. It's still refused while the old session is live somewhere.
- **The record takes the new session** once herdr confirms it, so a later
  plain resume continues the fresh conversation.

## Say what happened: `resume --json`

**`--json`** makes `resume` print one JSON line, whatever happens, with an
**`outcome`**: `resumed` or `started_fresh` (with where it landed), `alive`,
`busy`, `too_soon`, `dry_run`, `refused` or `failed` (with `why`). A job that
starts agents from mail can then tell "it's up" from "too soon, try later"
without reading prose. A successful resume's line now carries `outcome` with
or without `--json`.

- **One line on every path,** a usage error and a crash included.
- **Up is up:** once the agent is running, a later failure (its record, its
  first prompt) is a `warning` on `resumed` or `started_fresh`, not `failed`.
- **`--fresh` won't take an old conversation:** a launcher that passes
  `--resume` itself is refused, and an agent that comes up on its old
  session anyway is taken back.
- **`list` and `orphans` offer `--fresh`** for a record with no session to
  resume, and `--gated|--ungated` where the record is too old to say.
- An agent restarted in its own pane is recorded even if herdr can't be read
  right after the start.
