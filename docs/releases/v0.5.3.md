## What's new: the two-platform gate tells the truth

No change to `bowery` or `office` themselves: this release fixes the
pre-push gate and three tests that couldn't pass on macOS 26.

- **`scripts/ci-local` waits for each machine once.** Under bash 5.3,
  `wait -n` hands back a job it already reported (with its old status)
  while its pid is still in the list. So when this machine finished first
  and passed, the other machine's failure was never waited for: ci-local
  printed "here passed" twice and exited 0. Each side now leaves the list
  once it's reported, and a failure on either side exits 1.

### Tests

- `tests/test_ci_local.py` runs ci-local against a faked suite and a faked
  other machine: both pass, and the other machine fails after this one
  passed.
- The `hands_off_env` resume tests mark a python process, not
  `/bin/sleep`: macOS 26 hides an Apple platform binary's environment from
  `ps -E`, even from its owner, so a marked `sleep` read as "can't read"
  rather than "carrying". (Resume still refuses a process it can't read:
  that's the safe side.)
- The slow-plugin test accepts the kill in the plugin's `describe` too: a
  loaded machine's python start-up can pass the 500ms timeout there, and
  the office closes either way.
