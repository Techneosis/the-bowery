## Fixed: the bus node takes local clients on macOS

- **In root mode on macOS, the bus node dropped every local socket
  client.** It puts a seat to a connection by the socket's peer, and read
  that only on Linux (`SO_PEERCRED`), so on darwin it refused each one:
  `office bus status`, `office bus follow` and `office serve`'s hand-off
  to the node all failed with a broken pipe, and `office serve` answered
  every peer's call with a 502.
- On darwin the node now reads the peer the same way, from the kernel
  (`getsockopt(SOL_LOCAL, LOCAL_PEERCRED)`). Linux is unchanged. Dev mode
  still takes `OFFICE_BUS_AS`.
